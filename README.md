# Java concurrency

## Chapters 1–8 study guide

Open [`chapter1-summary/index.html`](chapter1-summary/index.html) in a browser for summaries of all eight chapters of *Modern Concurrency in Java* by A N M Bazlur Rahman. The single HTML file embeds the chapter figures, original study diagrams, and Java examples, so it works offline without additional files. Scoped values are final in JDK 25; the structured concurrency examples target the JDK 25 preview API and require preview features to be enabled. The Chapter 3 continuation example uses an internal API and is not for production use. The Reactor and framework examples require their respective dependencies and runtimes to execute.
